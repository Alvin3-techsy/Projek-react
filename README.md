# TodoList App memakai React + Vite

Aplikasi To-Do List yang dibuat menggunakan JavaScript, CSS, React + Vite

## Fitur

- Menambahkan tugas baru.
- Validasi input kosong.
- Menandai tugas selesai atau mengaktifkannya kembali.
- Menghapus tugas satu per satu.
- Menampilkan jumlah seluruh tugas dan tugas selesai.
- Menampilkan pesan ketika daftar tugas kosong.
- Filter tugas: Semua, Aktif, dan Selesai.
- Menyimpan tugas menggunakan localStorage.
- Menghapus seluruh tugas dengan konfirmasi.

## Teknologi

- React JS
- Vite
- CSS
- JavaScript
